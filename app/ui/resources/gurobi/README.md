# Capturas de las guías de Gurobi

Las guías de `GurobiGuide.cpp` muestran estas capturas, numeradas en el orden
en que aparecen en cada guía (`01.png`, `02.png`, ...):

- `instalar/01.png` … `instalar/13.png`: «Cómo instalar Gurobi».
- `licencia/01.png` … `licencia/13.png`: «Cómo obtener una licencia de Gurobi».

Se incrustan en el ejecutable al compilar (las que estén); las que falten se
muestran como «Captura pendiente».
